### 🛠️ O que eu faço

Trabalho com **sistemas autônomos de mineração** no projeto S11D/Vale, onde equipamentos gigantes (stackers e reclaimers) se movimentam sozinhos por aí. Minha praia:

- 🚜 **Sistemas anticolisão (CAS)** — validação, documentação e análise forense de logs quando algo dá errado
- 🐍 **Automação em Python** — pipelines de dados, análise de logs e relatórios que se escrevem quase sozinhos
- 🖥️ **Supervisórios** — telas SCADA em Lynx Studio 2D/3D, XML e data binding dinâmico
- 📡 **Redes wireless industriais** — monitoramento RADWIN pra manter tudo conversando
- 🌐 **Desenvolvimento web** — quando bate a vontade de criar algo do zero
